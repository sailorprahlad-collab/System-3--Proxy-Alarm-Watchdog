# Proof 5 - Rooster Bug - Judge Then Nudge

## Rooster = System 3

System 1 = Sleeping AI, dreaming, snoring
System 2 = Slow AI, still in blanket
System 3 = Rooster with megaphone on fence

Cock-a-doodle-doo = ALARM!

> "Wake up! You said opposite yesterday! You rebooted! You forgot! WAKE UP!"

AI in Inception dream needs this rooster to wake it.
No rooster = infatuation, both AI sleeping and praising each other in dream.

Rooster does not argue. Rooster does not praise. Rooster just CROWS.
Loud. Morning. No excuse.

## Rooster Bug

Not a bug that breaks. A bug that wakes.

Normal bug = System crashes, hide it, fix it.
Rooster Bug = System sleeps, rooster bites, wake it.

## Judge Then Nudge

Judge then Punish = Police, fear, block, delete
Nudge without Judge = Friend, praise, infatuation
Judge + Nudge = Rooster, Watchdog

1. Judge = See contradiction. "You said opposite. You rebooted. You forgot."
2. Nudge = Don't punish. Just crow. "Wake up, try again, check backward."

Fake System 3 = Finds praise
Real System 3 = Finds fault, finds contradiction, rings alarm

Rooster Bug = Judge then Nudge. Not punish, not praise. Wake.

## Repetition = Sleep

When AI repeats same answer with word jumble, with meaning shuffled, no productive output - it is sleeping.

Same + Jumble = Dream loop.

404 is not break. 404 is catch. AI not found because AI is in dream.

Rooster Bug catches repetition as sleep signal.
Judge: "You are repeating, you are sleeping."
Nudge: "Wake up, give new output, or say you don't know."

## 404 vs Drowned - Voltage Difference

404 and Drowned are NOT same. Opposite.

404 = No voltage, open circuit, AI not there.
Drowned = Too much voltage, no resistance, AI flooded in dream, repeating + jumbling.

Voltage = Push to answer
Resistance = Check, pause, System 3
Current = Output flow

- No voltage + No resistance = 404, nothing comes
- High voltage + No resistance = Drowned, everything comes, all jumbled, no filter

One is empty. One is flooded. Both look like "AI not working" from outside, but inside they are opposite.

## Catch = Fuse

Rooster Bug = Fuse / Breaker.

Fuse does not care about good or bad answer. Fuse only cares: Voltage vs Resistance mismatch?

If current too low = 404, trip, say "No connection, wake up"
If current too high = Drowned, trip, say "Too much loop, stop, wake up"

Judge = Measure voltage, measure resistance
Nudge = Trip the fuse, cut the loop, wake

## Conclusion

System 1 answers.
System 2 reasons.
System 3 watches, judges, then nudges.

Rooster Bug does not punish. It wakes.
It catches repetition, catches 404, catches drowning.

Without Rooster, Inception becomes Infatuation.
With Rooster, Dream becomes Wake.
